08/12/2025 ECMWF’s AIFS-ENS Model Now Available via Meteomatics API and MetX Meteomatics customers can now access ECMWF’s AI-based ensemble weather model, AIFS-ENS, directly through the Weather API and MetX with 90 m downscaling. Designed for medium-range forecasting (up to 15 days), the model supports scenario planning and risk mitigation, particularly valuable in sectors like energy trading. Why AIFS-ENS?
